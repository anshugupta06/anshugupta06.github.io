# Anshu Gupta — Portfolio

Personal portfolio website of **Anshu Gupta**, a final-year Computer Science and Engineering student at Graphic Era Deemed to be University, Dehradun. Built to showcase experience, projects, publications, and skills in full-stack development and machine learning.

**Live site:** [anshugupta06.github.io](https://anshugupta06.github.io)

## About

A single-page, dark-themed portfolio with a map/route visual motif — since much of the featured work involves geospatial and routing systems (AI travel planning, disaster monitoring). Built as a single self-contained HTML file: no build step, no dependencies to install, no framework required.

## Sections

- **Hero** — animated career-route timeline from 2023 to present
- **About** — summary with animated stat counters
- **Experience** — internship timeline (NIC, Graphic Era University research, Personifwy × IIT Roorkee)
- **Projects** — Smart Travel Planner, DisasterSphere, PhishShield, Sentiment Analysis with Bio-Inspired Optimization, and StayMatch, each linked to its GitHub repo
- **Skills** — languages, ML/AI, cloud & data, tools
- **Publications** — IEEE CITS 2025 paper and papers submitted to ICRTC 2026 / IJCESEN
- **Education** — degree history, certifications, hackathons
- **Contact** — email, phone, GitHub, LinkedIn

## Tech Stack

- Plain **HTML5 / CSS3 / JavaScript** — no framework, no build tooling
- Google Fonts: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [Inter](https://fonts.google.com/specimen/Inter), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
- Scroll animations via `IntersectionObserver`
- Inline SVG with `<animateMotion>` for the hero route line
- Fully responsive; respects `prefers-reduced-motion`

## Running Locally

No install needed — it's a static file.

```bash
git clone https://github.com/anshugupta06/anshugupta06.github.io.git
cd anshugupta06.github.io
open index.html   # or just double-click the file
```

## Deployment

Hosted on **GitHub Pages**, deployed from the `main` branch root.

To update the live site:

1. Edit `index.html`
2. Commit and push to `main`
3. GitHub Pages rebuilds automatically within a minute or two
